# Getting help

| You need help with… | Go to |
|---|---|
| **Using this skill** (installing it, wrong or outdated answers, missing topics) | [Open an issue](../../issues/new/choose) in this repo |
| **UNITS questions** (how to integrate, concepts) | Ask Claude with this skill loaded. Then try the [public docs](https://docs.finternetlab.io) and the Finternet Discord: https://discord.com/invite/x44vzPHmJ2 |
| **Your account, API access, developer tokens, scopes** | The web portal: https://sanctum.finternetlab.io (sandbox) or https://my.finternetlab.io (production) → **API Access**. Otherwise **engineering@finternetlab.io** |
| **Protected scopes, custom token programs, "Login with Finternet" onboarding, commercial terms** | **engineering@finternetlab.io** |
| **A UNITS platform bug** (API returns something wrong, an outage) | **engineering@finternetlab.io** with request/response (secrets removed), environment and timestamps |
| **Security issues** | See [SECURITY.md](SECURITY.md). Don't post them publicly. |

The sandbox (`sanctum`) normally runs **08:00–21:00 IST, Monday–Friday**. If it's unreachable outside those hours, that's expected.
